# MOWRA 基本要件

記録日: 2026-10-01

本書は、プロジェクトの最も基本的な要件を記録する。現在の実装状況とは区別し、今後の設計・実装の判断基準とする。

## 目的

MOWRAはソフトウェアテストの自動化支援ツールである。テスターに要求されるスキルレベルを下げ、簡単なテストの設計と打鍵の自動化を支援する。

## 基本要件

1. **テスターに要求されるスキルレベルを下げる**
   - 高度なテスト設計スキルを前提とせず、簡単なテストを設計・実行できるように支援する。
2. **JSTQB Foundation Level（FL）をベースにする**
   - テスト観点の導出およびテストケースの設計は、JSTQB FLを基礎とする。
3. **CodexまたはClaudeでインプット資料を分析する**
   - インプット資料をCodexまたはClaudeに渡し、テスト観点の導出に利用する。
4. **資料の精度を問わず、現物も確認して観点を導き出す**
   - 資料が不完全、不正確、または古い場合でも、テスト設計を支援する。
   - 資料だけでなく、テスト対象の実際の画面や動作も確認しながら、テスト観点を導き出す。
5. **打鍵を自動化する**
   - 設計したテストに基づく画面操作・入力などを自動化し、テスターの実行作業を支援する。

## 基本的な利用の流れ

インプット資料を渡す → CodexまたはClaudeが資料を分析し、現物も確認する → テスト観点を導出する → JSTQB FLをベースに簡単なテストを設計する → 打鍵を自動化する。
